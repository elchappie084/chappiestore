# Chappie Store

Site estático para publicar no GitHub (branch `main`) e na Vercel.

## Publicação
1. Coloque `index.html`, `chappie-logo.png` e `vercel.json` na raiz do repositório, na branch `main`.
2. Na Vercel, importe o repositório ou reconecte o projeto existente.
3. Em **Settings > Build and Deployment**, escolha **Framework Preset: Other**, **Root Directory: `./`**, **Build Command: vazio**, **Output Directory: `.`**.
4. Faça um novo deploy da branch `main`.
